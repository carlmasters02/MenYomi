Six specialists, 一 one clean result.

MenYomi isn't one model doing everything — it's a small team of purpose-built systems, each handling the step it's best at. Here's who does what.

N

Nosana Reads the menu

読み取り · self-hosted OCR

The menu image first goes to a Nanonets OCR model hosted on Nosana's decentralized GPU network. Running the vision model on dedicated hardware means MenYomi can read handwritten boards and awkward photos without depending on a single provider — and it falls back gracefully if the GPU is ever offline.

Q

Qwen Cloud Vision backup + reading

視覚 · multimodal fallback

Qwen's multimodal model is the reliable second reader. Strong on Japanese text, it steps in instantly whenever the self-hosted OCR is unavailable, so a menu always gets read — the app never leaves you staring at a spinner.

G

GMI Cloud Translates & enriches

翻訳 · the orchestrator

Once the dishes are read, GMI turns them into something useful: natural English names, short descriptions, allergen tags, and a one-line cultural note per dish. It's the layer that takes raw text and makes it genuinely helpful for a diner.

&

ai& Japanese descriptions

日本語 · Japan-based inference

Translation shouldn't only go one way. ai& — running on infrastructure inside Japan — writes natural Japanese descriptions so you can point at exactly what you want at the counter, and so locals reading over your shoulder see something fluent.

D

Daytona Runs code safely

実行 · secure sandbox

When MenYomi builds your downloadable menu page, an AI generates the HTML and Daytona runs it inside an isolated sandbox to validate it before it ever reaches you. Agent-written code executes in a safe, disposable environment — never on your machine or the server directly.

Q

Qoder Where it was built

開発 · agentic IDE

The entire application was developed in Qoder, an agentic coding environment. Its repo-aware assistant and multi-agent workflow made it possible for a single developer to wire six platforms together into one working product.

Built as a solo project at the Agent Forge AI Hackathon: Tokyo — and taken further as a real product since.
